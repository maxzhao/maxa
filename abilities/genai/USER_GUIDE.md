# GenAI 用户使用示例

本技能用于图片生成与编辑、文本转语音、视频生成、图片提示词设计、模板化交付、案例逆向和 GenAI Adapter 开发。你可以直接描述结果，不需要知道内部工具或文件名。

## 快速触发

- “帮我生成一张图片 / 帮我生图。”
- “帮我编辑这张图 / 根据参考图重绘一张。”
- “帮我设计图片提示词 / 只要提示词，不要生成图片。”
- “用 genai 调用 image_generate / image_edit。”
- “把这段文本转成语音 / 调用 audio_speech。”
- “根据提示词和参考图生成视频 / 调用 video_generate。”

## 普通生图与提示词设计

短句、段落或结构化 brief 都可以，不强制固定格式。重点是明确画面用途、主体、构图、可见细节和约束；图中文字应逐字给出，需要时指定位置、字体与出现次数。

- “生成一张赛博朋克风格城市夜景图。”
- “把这个想法整理成适合生图模型的 prompt。”
- “这个 prompt 已经很具体，只整理结构，不要增加人物、道具或品牌。”
- “图片里必须准确出现这些文字：……，不要额外字符。”

## 文本转语音与视频生成

- “把下面文字合成为语音：……”
- “使用指定声音和语速朗读。”
- “生成一个 6 秒视频：镜头环绕桌上的产品。”
- “参考这些本地图片生成视频，并保持主体外观一致。”

## 多轮编辑与候选分支

参考图会按人物、产品、风格、服装或背景等角色分别说明。每次修改尽量聚焦一个变化，并重新明确身份、几何、布局、文字和周围内容等保留项。

- “基于上一张继续改，只调整色调。”
- “从候选图里选第 2 张继续做。”
- “保留人物和构图，把背景换成雪山。”
- “只修复上一张中的文字错误。”

如果某个区域必须逐像素不变，应使用确定性编辑或合成，而不是只依赖提示词。

## 专家检查与视觉验证

- “生成前先从摄影、品牌或 UI 专家视角检查 brief。”
- “生成后检查文字、布局、品牌和主体是否正确。”
- “编辑图允许正常重绘；按第一眼是否仍是同一主体审阅，不要求像素或轮廓 1:1。”
- “局部检查 Logo、小字或 UI 细节是否清楚。”

工具成功只表示文件生成成功，不代表内容已经通过。高风险交付物会继续检查文字、结构、参考一致性、真实尺寸和格式。

## 类别化视觉任务

你可以直接说明交付物类型：

- UI/UX：“生成移动 App 界面。”“做 Web / SaaS dashboard。”
- 信息图/技术图：“做技术架构图。”“把系统流程画成信息图。”
- 海报/排版：“做活动海报。”“生成中文大标题字体海报。”
- 产品/电商：“生成商品主图。”“做电商 product hero。”
- 摄影/写实：“生成写实产品摄影图。”“做电影感街拍照片。”
- 人物/角色：“做角色设定图。”“保持角色一致性，做多张姿势。”
- 参考图编辑：“保留主体，把风格改成水彩。”“参考两张图融合。”

## 生产型交付物

- 应用商店截图：“帮我做一套 App Store / Google Play 宣传图。”
- Logo / 品牌：“生成 Logo concept grid。”“做 brand identity board。”
- 商业视觉：“做 strategy one-pager。”“生成咨询风格商业信息图。”
- 科研图：“做论文方法图。”“生成 research pipeline figure，不要编造数据。”
- 演示页：“生成 16:9 pitch slide。”“做 executive update slide。”
- Storyboard：“把剧情画成九宫格分镜，保持角色一致。”
- 游戏 Sprite：“生成角色 Sprite Sheet，明确帧数、动作、网格和留白。”

这些请求可以使用结构化模板。模板只提供可复用字段和默认建议，不会覆盖用户明确给出的尺寸、文案、数据或视觉约束。

## 模板化与批量交付

- “帮我设计一套可复用的截图模板。”
- “批量生成前先设计模板变量和 prompt 草案。”
- “只输出模板化方案，不要直接生成。”
- “先列出缺失变量，再生成第一张样例。”

独立候选可以并行；需要沿用上一张、用户选择、参考图或已验收状态时会保持顺序执行。批量、高分辨率或多候选任务会先说明成本与调用范围。

## 参数与能力预检

- “调用前检查 requested_size、quality 和 output_format。”
- “保留我给出的 WIDTHxHEIGHT；如果后端不支持，先说明，不要静默改尺寸。”
- “我提供了本地 mask，检查接口是否支持。”
- “把旧图片 API 参数改成当前 GenAI 公共参数。”
- “不要擅自切换 Adapter 或报告当前 Adapter 身份。”

接口限制会按实际错误处理，不会被误写成通用模型限制。成功后仍会核对返回文件的实际尺寸和格式。

## 什么时候不要使用生成式图片

- “这个 SVG 图标应该直接改源码，不要生成位图。”
- “我需要可编辑的 HTML/CSS 界面，不要生成截图式图片。”
- “先判断应该生图，还是直接修改现有矢量或代码资产。”

## 案例逆向与规则沉淀

- “逆向这张图可能使用的 prompt。”
- “分析这个案例的构图、材质和视觉控制项。”
- “把这组案例提炼为可复用的提示词模板。”

## Adapter 开发

- “新增一个 GenAI Adapter。”
- “扩展当前 Adapter 的图片能力。”
- “调试 image_generate 参数兼容问题。”

Adapter 开发会单独检查公共字段映射、配置能力、错误边界和兼容性，不会为了当前调用随意修改默认后端。
