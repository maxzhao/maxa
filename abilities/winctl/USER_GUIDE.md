# winctl 用户指南

`winctl` 用来让 Agent 从 WSL 控制 Windows 桌面。你可以直接用自然语言描述要观察、点击、输入、拖拽、管理窗口或维护 WinCtl Server 的目标；不需要知道内部脚本或参考文档路径。

## 你可以怎样触发

- “帮我看一下 Windows 桌面现在是什么状态。”
- “截图桌面并告诉我可以点击哪些地方。”
- “用 winctl 聚焦 Chrome，然后点一下页面上的登录按钮。”
- “帮我操作 Windows 桌面，把这段中文粘贴到当前输入框。”
- “查找标题包含 Notepad 的窗口并截图验证。”
- “把这个窗口移动到第二个虚拟桌面。”
- “帮我调试/扩展 winctl-server 的一个新动作。”

## 观察与截图

适合需要先看清 Windows GUI 再决定下一步的场景。

示例说法：

- “截图整个 Windows 桌面，分析当前有哪些窗口和可交互按钮。”
- “截图当前 Chrome 窗口，标出主要按钮的大概坐标。”
- “帮我验证刚才点击之后页面有没有变化，截图对比一下。”
- “我不知道该点哪里，先截图并告诉我下一步建议。”

覆盖能力：桌面截图、窗口截图、截图文件分析、操作后复查。截图坐标与截图像素一致，Agent 会优先通过截图确认再操作。

## 查找、聚焦和调整窗口

适合要操作特定 Windows 应用、避免误点其他窗口的场景。

示例说法：

- “列出当前所有窗口，帮我找到标题包含 Edge 的那个。”
- “聚焦 Notepad 窗口，然后截图确认它在前台。”
- “把 Chrome 窗口移动到屏幕左上角并调整为 1280×720。”
- “获取这个窗口的详细信息，包括位置、大小和句柄。”
- “查找 Tauri/WebView2 子窗口，后续点击请针对子窗口操作。”

覆盖能力：窗口列表、按标题过滤窗口、获取窗口信息、聚焦窗口、调整窗口位置大小、查找子窗口。涉及具体窗口时，可以直接说应用名或标题关键字。

## 鼠标点击、移动、滚动和拖拽

适合执行桌面坐标或窗口内相对坐标操作。

示例说法：

- “截图后点击坐标 800,400，并再次截图验证。”
- “把鼠标移动到按钮上方，确认 hover 状态。”
- “向下滚动 5 格后截图。”
- “在窗口内从 200,50 拖到 400,300。”
- “对这个窗口使用相对坐标点击，不要受窗口位置影响。”
- “尝试用窗口消息方式拖拽这个控件。”

覆盖能力：桌面坐标移动、点击、拖拽、滚动；窗口相对坐标点击、拖拽；窗口消息拖拽。你只需说明目标位置、动作和是否需要验证，Agent 会选择桌面坐标或窗口坐标。

## 键盘输入、快捷键和中文粘贴

适合输入文本、触发快捷键、复制页面内容或打开开发者工具。

示例说法：

- “在当前输入框粘贴这段中文：你好，世界。”
- “按 Ctrl+Shift+I 打开开发者工具，然后截图确认。”
- “按 Enter 提交当前表单。”
- “按 Ctrl+A、Ctrl+C，然后读取剪贴板内容。”
- “输入 Hello World，每个字符之间稍微停顿一下。”

覆盖能力：普通文本输入、单键按下、组合快捷键、剪贴板读取/写入。中文、长文本和特殊字符优先让 Agent 走“写入剪贴板 → Ctrl+V”的方式，通常比模拟逐字输入更可靠。

## 剪贴板读写与页面文本提取

适合把内容送入 Windows 应用，或从当前应用复制文本给 Agent 分析。

示例说法：

- “把这段内容复制到 Windows 剪贴板并粘贴到当前窗口。”
- “读取当前剪贴板内容，看看复制成功没有。”
- “全选当前页面内容并复制，读取剪贴板后总结文本。”
- “把生成的命令粘贴到 Windows 终端里。”

覆盖能力：设置剪贴板、读取剪贴板、配合快捷键复制/粘贴、读取页面文本。

## 虚拟桌面管理

适合整理 Windows 桌面或把窗口移动到指定虚拟桌面。

示例说法：

- “列出 Windows 当前有哪些虚拟桌面。”
- “切换到第二个虚拟桌面。”
- “把当前 Chrome 窗口移动到第 2 个虚拟桌面。”
- “找到这个窗口后，把它移到名为 Work 的桌面。”

覆盖能力：列出虚拟桌面、按索引或名称切换虚拟桌面、把窗口移动到指定虚拟桌面。

## 光标、DPI 和底层窗口消息

适合定位坐标问题、处理高 DPI 缩放问题，或对普通鼠标操作不可靠的窗口发送 Win32 消息。

示例说法：

- “获取当前鼠标位置，帮我确认坐标。”
- “查看这个窗口的 DPI 信息，确认坐标缩放是否正常。”
- “普通点击无效，请尝试给窗口发送 Win32 消息。”
- “用底层窗口消息点击/拖拽这个 Tauri WebView 控件。”

覆盖能力：读取光标位置、查询 DPI 信息、发送 Win32 `post_message`、辅助排查窗口坐标与输入问题。

## 常见完整工作流

### 先观察再点击

你可以说：

> “截图桌面，分析登录按钮坐标，点击它，然后再截图验证是否进入下一步。”

Agent 会按“截图 → 分析 → 操作 → 再截图验证”的闭环执行。

### 操作特定窗口

你可以说：

> “找到标题包含 Chrome 的窗口，聚焦它，截图窗口内容，然后点击右上角的菜单按钮。”

Agent 会先查找窗口并聚焦，避免对被遮挡窗口误操作。

### 粘贴中文或长文本

你可以说：

> “把下面这段中文粘贴到当前输入框，然后按 Ctrl+Enter 发送：……”

Agent 会使用剪贴板粘贴，而不是逐字模拟输入。

### 滚动页面并验证

你可以说：

> “在当前页面向下滚动几次，直到看到设置区域；每次滚动后截图判断。”

Agent 会结合滚动、截图和视觉分析完成。

### 读取当前页面文本

你可以说：

> “复制当前页面的全部文本，读取剪贴板后总结一下主要内容。”

Agent 会用快捷键复制，再读取剪贴板。

### Tauri / WebView2 子窗口操作

你可以说：

> “这是 Tauri 应用，请先找 WebView2 子窗口，再在子窗口相对坐标中点击设置按钮。”

Agent 会查找子窗口，尽量使用更稳定的窗口相对坐标。

## 可请求 Agent 使用的资源入口

你不需要记住文件名，但可以这样表达：

- “请先按 winctl 的操作模式执行，不要直接猜坐标。”  
  Agent 会参考使用模式，按截图、分析、操作、验证等闭环处理。
- “我想知道 winctl 支持哪些动作和参数。”  
  Agent 会查看自带 CLI 帮助，列出可用动作。
- “请用 winctl 自带脚本完成这个 Windows 桌面操作。”  
  Agent 会调用统一脚本执行截图、窗口、鼠标、键盘、剪贴板、虚拟桌面等动作。
- “我要维护 winctl-server / 新增一个动作，请按开发指导做。”  
  Agent 会参考服务端开发指导，处理协议、handler、客户端动作表、DPI、截图、PostMessage、虚拟桌面等实现细节。

当前 Ability 的可达资源类别包括：执行脚本、使用模式参考、Server 开发参考。没有单独的 assets 或 hooks 资源需要用户触发。

## 注意事项

- 尽量说明目标应用、窗口标题关键字、期望动作和完成后的验证标准。
- 如果要点击某个界面元素，最好允许 Agent 先截图分析坐标。
- 如果要输入中文或长文本，请直接说“粘贴”，Agent 会优先使用剪贴板。
- 对窗口操作建议先让 Agent 查找并聚焦窗口，再执行键盘或鼠标动作。
- 操作 Windows GUI 可能受窗口遮挡、焦点、权限或应用实现影响；重要操作应要求截图验证。
