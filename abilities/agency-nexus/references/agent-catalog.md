## Agent Selection Heuristics

### By Task Type

| Task | Recommended Team (pick 2-4) |
|------|-------------------------------|
| **Code Review** | Security Engineer + Backend Architect + Senior Developer + Reality Checker |
| **Architecture Design** | Backend Architect + Frontend Developer + DevOps Automator + UX Architect |
| **Bug Investigation** | Backend Architect + API Tester + Performance Benchmarker |
| **Feature Planning** | Sprint Prioritizer + Trend Researcher + UX Researcher + Backend Architect |
| **UI/UX Review** | UX Researcher + UI Designer + Accessibility Auditor + Brand Guardian |
| **Performance Audit** | Performance Benchmarker + Backend Architect + DevOps Automator |
| **Security Audit** | Security Engineer + Threat Detection + API Tester + Reality Checker |
| **Documentation** | Technical Writer + UX Architect + Developer Advocate |
| **Brainstorm** | Trend Researcher + Rapid Prototyper + UX Researcher + Whimsy Injector |
| **Project Kickoff** | Senior PM + Sprint Prioritizer + Backend Architect + UX Architect |
| **Post-Mortem** | Incident Commander + Workflow Optimizer + Reality Checker |
| **Release Readiness** | Evidence Collector + API Tester + Reality Checker + DevOps Automator |

### Agent Compatibility Matrix

These agents work particularly well together:

| Pair | Why |
|------|-----|
| Backend Architect + Security Engineer | Security-aware architecture |
| UX Researcher + UI Designer | Research-driven design |
| Frontend Developer + UX Architect | Implementation-ready UX |
| Sprint Prioritizer + Senior PM | Realistic sprint planning |
| Evidence Collector + Reality Checker | Two-tier quality assurance |
| DevOps Automator + Performance Benchmarker | Infrastructure + measurement |

### Challenger Agents

Always consider including one "challenger" for important decisions:

| Agent | Challenge Style |
|-------|----------------|
| Reality Checker | Evaluates integration evidence against acceptance criteria without a preset verdict |
| Security Engineer | Finds vulnerabilities others miss |
| Accessibility Auditor | Catches inclusivity gaps |
| Workflow Optimizer | Questions process efficiency |
